# Local workspace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Поставить локальное приложение Mac с Markdown, редактором, медиа, Data View по тегам и графом проекта.
**Architecture:** Tauri 2/Rust владеет дисковыми операциями; React/TypeScript показывает редактор и четыре вида одного набора страниц. SQLite — восстанавливаемый индекс; Markdown, YAML и оригиналы вложений — источник истины.
**Tech Stack:** Tauri 2, React, TypeScript, Vite, Tiptap, React Flow, Rust, SQLite, Vitest.
**Spec:** `docs/superpowers/specs/2026-10-20-local-notes-design.md` (включая поправку §13).

## Global Constraints

- Личное использование на Mac, целевая минимальная версия macOS 14, Apple Silicon.
- Совместимость с Obsidian не требуется; нужны выбор страниц по тегам и граф их соединений.
- Нет квот приложения на оригиналы вложений; копирование не загружает весь файл в память.
- Автосохранение после 500 мс паузы, при непрерывном вводе не реже раза в 2 секунды.
- История 30 дней / 500 MiB, превью до 250 MiB; оригиналы, корзина и конфликты автоматически не удаляются.
- Интерфейс на русском, понятные состояния ошибок; SQLite можно восстановить из файлов.
- Пользователь разрешает реализацию после поправки; повторный handoff не требуется. Исполнение в текущей изолированной папке на ветке `feat/local-workspace`.

## Review Focus

- Небезопасный путь или symlink не даёт записывать вне корня: Task 2, реальный временный каталог.
- Сторонняя запись не теряется за локальным автосохранением: Task 2, устаревшая ревизия.
- Дубли имён не создают случайных рёбер графа: Task 1, два одноимённых файла.
- Старый async-ответ сохранения не подменяет открытую страницу: Task 4, сквозная смена вкладок во время записи.
- Пустой/недоступный vault и некорректный YAML не ломают настройки и остальные заметки: Task 2 + Task 7.

## Files and interfaces

- `src/core/model.ts`: `Note`, `DataView`, `Graph`; `selectNotes(notes, view)`, `buildGraph(notes, options)`.
- `src/core/model.test.ts`: выбор по тегам, поиск, ссылки, граф и неоднозначность.
- `src/core/bridge.ts`: типизированные вызовы native-команд; браузерный адаптер только для явно обозначенной демонстрации.
- `src-tauri/src/vault.rs`: `Vault::open(root, index_path)`, `list`, `read`, `save(path, expected_revision, content)`, `create`, `trash`, `restore`, `history`, `attach`; реальные файловые проверки.
- `src-tauri/src/lib.rs`: Tauri commands, native folder/file dialogs, persist last vault, reveal/open, safe asset protocol.
- `src/hooks/useWorkspace.ts`: загрузка, последовательная очередь записи, таймеры, конфликты, вкладки.
- `src/components/{Sidebar,Editor,DataViews,GraphView,Settings,Search}.tsx`: рабочие поверхности.
- `src/App.tsx`, `src/styles.css`: композиция и тема.
- `scripts/verify.mjs`, `README.md`, `docs/verification.md`: воспроизводимая проверка и статус поставки.

### Task 1: Модель заметок, Data View и граф

- [ ] Написать тесты: OR включает страницы A/B с тегами project/design, AND — только A с обоими; пустой фильтр включает все; явная ссылка A→B даёт одно направленное ребро; общий тег даёт два ребра принадлежности; неоднозначная ссылка не даёт ребра.
