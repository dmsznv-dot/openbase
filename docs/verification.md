- `npm test`: 11 тестов, 0 ошибок. Членство по тегам OR/AND, граф, неоднозначные ссылки внутри и вне выбранного набора, приоритет относительного пути, разрешение вложений, очередь записи и ожидание flush.
- `cargo test --offline --manifest-path src-tauri/Cargo.toml`: 12 тестов проходят; отдельный нагрузочный тест исключён из обычного запуска и выполнен отдельно. Проверяются реальные временные папки, конфликт ревизии, неизвестные YAML-свойства, повреждённый YAML, обход путей/symlink, корзина и коллизия восстановления, история и её очистка, дубликат идентичности, отмена копирования, индекс и перемещение со ссылками.
- `cargo clippy --offline --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`: проходит без предупреждений.
- `npm run build`: TypeScript и production-сборка проходят. Сборщик предупреждает о крупном редакторском JS-чанке; это известный вопрос оптимизации размера, не ошибка сборки.
- `node scripts/browser-verify.mjs`: 7 браузерных сценариев, 0 page errors. Четыре представления используют одинаковые страницы, граф открывает страницу, быстрое переключение исходника сохраняет изменения, заголовок и теги сохраняются, поиск находит новую запись, настройки в тёмной теме помещаются в 1024×700.
- Release `.app` собран для arm64. LaunchServices запускает приложение с кодом 0; процесс остаётся запущенным. Пакет подписан локальной ad-hoc подписью и проходит `codesign --verify --deep --strict` после запечатывания ресурсов.

## Набор из 100 заметок

По прямому указанию пользователя проверка ограничивается 100 заметками. Нагрузочный прогон на 10 000 не выполняется.

```sh

Буфер копирования фиксирован: 1 MiB. Во всех трёх измерениях существенны кэш ОС, тип диска и синтетическое содержимое.

## Независимый просмотр кода

Отдельный reviewer выявляет риски потери текста при переключении Markdown, при восстановлении YAML и при навигации во время сохранения, а также ошибки разрешения ссылок. Реализация исправляется; соответствующие проверяемые случаи модели и переключения редактора проходят. Дополняются обработка дубликатов ID, история, отмена/прогресс вложений и файловое перемещение. Полный повторный независимый аудит после исправлений не заявляется.

## Практические пределы проверки

Браузерный прогон использует явно обозначенный демонстрационный адаптер. Он проверяет интерфейс и его состояние, но не подменяет файловые тесты Rust и не доказывает весь GUI→IPC→диск сценарий. Нативные диалоги Finder, реальное перетаскивание из Finder и закрытие окна с незавершённой записью не автоматизируются этим прогоном. Запуск настоящего `.app` проверен отдельно.

Не выполняются испытания физического отказа диска, внезапного отключения питания, конфликтов облачных провайдеров папок и всех гонок со сторонними редакторами. Последовательность записи использует временный файл, fsync, проверку ревизии и атомарную замену, но это не обещание абсолютной защиты от всех внешних отказов.

Изображения используют оригиналы, отдельный дисковый кэш миниатюр не реализован. Поля дополнительных свойств редактируются в форме страницы; таблица первой версии показывает название, теги, статус и дату. Нет полного визуального конструктора произвольных столбцов и фильтров свойств. Эти границы первой поставки явно описаны в README и не выдаются за проверенные функции.

ECC не обнаружен среди доступных локальных скиллов и не используется. Impeccable применяется к интерфейсу, Superpowers — к спецификации, плану, тестированию и обзору кода. Исходники или ресурсы из присланного Notion DMG не извлекаются.
