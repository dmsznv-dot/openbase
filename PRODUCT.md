# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

Desktop macOS application using Tauri; its UI is a webview, not an iOS app.

## Stack

Confirmed: Tauri 2, React, TypeScript, Rust, local Markdown files and rebuildable SQLite index.

## Users

Dmitry, a creative producer, uses it personally on a Mac for project notes, references and connected pages.

## Product Purpose

Write and organize pages with familiar Notion interactions, store all content in a chosen local folder, and see a project's connected pages in a tag-scoped Data View.

## Capabilities and Constraints

Offline; no account; media originals have no application quota; note properties in YAML. Table, cards, kanban and graph are views of the same pages. Tag hubs express project membership; page links express explicit connections. No Obsidian compatibility requirement. No collaboration or AI in v1.

## Brand Commitments

Familiar, restrained Notion-like desktop editor. Russian UI. Readable light/dark themes. No ornamental dashboard or marketing landing page.

## Evidence on Hand

Approved specification and graph amendment in docs/superpowers/specs. User explicitly authorizes implementation after amendment. Supplied Notion DMG is uninspected; do not claim to reuse its code. ECC is not available in the inspected local skill directories.

## Product Principles

- Files remain accessible outside the app.
- Saving and recovery states are visible.
- A project view shows the connections between its pages.
- Everyday writing requires few controls.
