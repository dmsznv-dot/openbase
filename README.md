# Local Notes

Локальное приложение для Mac: Markdown-страницы с блочным редактором, вложениями, представлениями данных и графом проекта. Пользователь выбирает папку; облако и аккаунт не нужны. Совместимость с Obsidian не требуется и не заявляется.

[Скачать актуальную сборку для Mac](https://github.com/dmsznv-dot/openbase/releases/latest)

## Запуск

Распакуйте `LocalNotes-macOS-arm64.zip`, перенесите `Local Notes.app` в удобную папку и откройте. На первом экране выберите существующую или новую папку для заметок. Эта сборка предназначена для Apple Silicon и macOS 14 или новее; фактически проверена на macOS 15.7.1.

Приложение имеет локальную ad-hoc подпись, без Developer ID и нотарификации Apple. Если macOS блокирует скачанную сборку, используйте системный пункт «Открыть всё равно» в «Конфиденциальность и безопасность» для этого приложения. Глобальное отключение защиты не требуется.

Боковое меню сворачивается и открывается кнопкой слева в верхней панели. Последнее состояние сохраняется между запусками.

## Проект и его связи

1. Создайте несколько страниц. В поле «Теги» перечислите общий тег проекта через запятую.
2. Создайте Data View кнопкой рядом с этим разделом слева.
3. В фильтре «Теги» выберите нужные теги и режим «любой» или «все».
4. Переключайтесь между таблицей, карточками, канбаном и вкладкой «Связи».
5. В графе страницы соединяются явными внутренними ссылками, а общая принадлежность видна через узлы тегов. Нажатие на страницу открывает её. Нажатие на тег уточняет фильтр.

В Markdown можно написать `[[Название страницы]]` или обычную ссылку `[Название](Папка/Страница.md)`. Неоднозначные имена не создают случайных соединений. При необходимости используйте явный относительный путь.

## Представления отдельной страницы

У каждой страницы есть вкладки **Текст**, **Таблица**, **Канбан** и **Карточки**. Первое представление открывает текст и вложения; остальные показывают её непосредственные вложенные страницы. «Новая страница» в таком представлении создаёт дочернюю запись, сохраняя иерархию. Страницы других проектов в эту выборку не попадают. Фильтр по тегам уточняет набор вложенных страниц.

Переключение вида не преобразует и не удаляет текст, вложения или дочерние страницы. Последний выбранный вид и его фильтр сохраняются в YAML страницы (`localnotes.page_view`) и восстанавливаются при повторном открытии.

При наведении на страницу в сайдбаре или фокусе с клавиатуры появляется кнопка **⋯**: добавить/убрать из избранного, переименовать заголовок, удалить в корзину. Имя Markdown-файла меняется отдельно через путь над заголовком.

В разделе **Связи** можно перетаскивать узлы: связанные страницы плавно подтягиваются за ними. «Пауза» останавливает физику, сохраняя возможность ручного перемещения. При системном уменьшении движения физика изначально выключена; её можно включить вручную. Поиск, наведение и фоновый опрос файлов не сбрасывают позиции и масштаб. При изменении состава графа существующие узлы сохраняют свои позиции, а новые добавляются рядом со связанными узлами. После выхода из представления раскладка строится заново. Позиции графа между сеансами не сохраняются.

## Запись и файлы

- `/` открывает меню блоков. Пункт «Подстраница» создаёт дочернюю страницу текущей; ссылки на вложенные страницы доступны под текстом родительской страницы. Ручка слева от блока позволяет его перетащить; в панели также есть кнопки перемещения вверх и вниз.
- Кнопка Markdown переключает исходный и визуальный режим. Неподдерживаемые конструкции и повреждённый YAML открываются в исходном режиме для сохранности данных.
- «Скрепка» добавляет файл. Также можно перетащить файл Finder в открытую страницу. Копирование показывает прогресс и допускает отмену.
- Изображения показаны на странице, поддерживаемые аудио/видео имеют проигрыватель, PDF и другие вложения открываются системным приложением. Наличие файла не гарантирует поддержку его кодека встроенным движком.
- Путь над заголовком открывает переименование/перемещение файла. Заголовок страницы и имя файла — отдельные значения.
- Кнопка «История» восстанавливает контрольные версии. Удаление страницы перемещает её в корзину, не удаляя общие вложения.

Приложение не задаёт лимит размера медиа. Реальными ограничениями остаются свободное место, файловая система и возможности декодирования ОС. Внешний ролик по URL не скачивается автоматически для офлайна.

## Формат папки

Текст хранится в `.md`, свойства — в YAML frontmatter, оригиналы файлов — в `Вложения/`. Служебные определения представлений, история, корзина и конфликтные копии находятся в `.localnotes/`. Поисковый SQLite-индекс размещается отдельно в данных приложения и может быть перестроен из файлов.

Данные хранятся без обязательного проприетарного JSON-документа. Форматирование Markdown может нормализоваться визуальным редактором. YAML-комментарии и исходный порядок полей не обещаются побайтово неизменными; неизвестные значения сохраняются семантически.

## Горячие клавиши

| Действие                  | Клавиши |
| ------------------------- | ------- |
| Поиск                     | ⌘K      |
| Новая страница            | ⌘N      |
| Сохранить сейчас          | ⌘S      |
| Закрыть поиск или историю | Escape  |
| Жирный / курсив           | ⌘B / ⌘I |

## Сборка исходников

Требуются Node.js 24+, npm, стабильный Rust и Apple Command Line Tools. Зависимости фиксируются в `package-lock.json` и `src-tauri/Cargo.lock`.

```sh
npm ci
npm test
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri -- build --bundles app
codesign --force --deep --sign - --identifier studio.dmitry.localnotes "src-tauri/target/release/bundle/macos/Local Notes.app"
```

Для браузерного просмотра интерфейса: `npm run dev`, затем `http://127.0.0.1:1420/?demo`. Этот режим явно показывает демонстрационные данные и не является способом работать с файлами Mac.

Для браузерной проверки: `npx playwright install chromium`, `npm run build`, `node scripts/browser-verify.mjs`.

## Ограничения первой версии

Нет совместной работы, синхронизации между устройствами, AI, полного импорта Notion или поддержки форматов Obsidian. Фильтр проекта работает по тегам; сложные выражения Dataview и вычисляемые свойства отсутствуют. Граф показывает не более 500 страниц и сообщает об этом, другие представления сохраняют полный набор.

Параметры истории пока фиксированы: 30 дней и бюджет 500 MiB с защитой последней версии каждой страницы. Корзина и конфликтные копии не очищаются автоматически. Отдельный дисковый кэш миниатюр и его настройки в этой сборке не реализуются: изображения показывает WebKit из оригиналов. При аварийном прерывании перемещения оригинальные тексты остаются в журнале `.localnotes/moves/`; автоматический мастер восстановления такого перемещения пока отсутствует.

Проверки и их практические пределы описаны в `docs/verification.md`.
