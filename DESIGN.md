# Local Notes design

The user chooses the familiar editor convention: Notion pages and Obsidian-style graph functionality. Preserve the convention at full craft; do not run a speculative identity tournament.

Main surface mode: Operate / Read. Muted stone sidebar, warm paper content, graphite text, restrained muted green accent. System macOS sans UI; note body at 16px, 1.65 line height, 70ch measure. Header 32px, semibold. Controls are compact and use one consistent outlined SVG icon family. Sidebar 240px; tabs and toolbar remain in place as the document scrolls. Property rows sit under the title, graph lives in a full-width workspace with tag hubs distinguishable from page nodes. Settings and contextual help stay out of the writing flow.

Visible focus, contrast, accessible control names, reduced motion and explicit loading/error/empty states are required. Use keyboard shortcuts customary on Mac. Dark theme follows the system unless overridden. The UI contains no fabricated project content; optional sample content is clearly labeled.
