# Local Notes design

The user chooses the familiar editor convention: Notion pages and Obsidian-style graph functionality. Preserve the convention at full craft; do not run a speculative identity tournament.

Main surface mode: Operate / Read. Muted stone sidebar, warm paper content, graphite text, restrained muted green accent. System macOS sans UI; note body at 16px, 1.65 line height, 70ch measure. Header 32px, semibold. Controls are compact and use one consistent outlined SVG icon family. Sidebar 240px; tabs and toolbar remain in place as the document scrolls. Property rows sit under the title, graph lives in a full-width workspace with tag hubs distinguishable from page nodes. Settings and contextual help stay out of the writing flow.

Visible focus, contrast, accessible control names, reduced motion and explicit loading/error/empty states are required. Use keyboard shortcuts customary on Mac. Dark theme uses neutral graphite surfaces (#202124 content, #191a1d sidebar), cool gray borders and restrained blue accents. It follows the system unless overridden. Page layouts appear as persistent Text / Table / Kanban / Cards tabs; the latter three show direct child pages. Sidebar page menus appear on hover or keyboard focus. Graph links behave as damped springs while dragging; physics sleeps when settled, paused or hidden and defaults off for reduced motion. The UI contains no fabricated project content; optional sample content is clearly labeled.

Sidebar collapses from the main topbar and remembers its state; the reopen control remains visible with a 90px inset for native macOS window controls. The sidebar has no local-storage footer badge. Slash menu offers creating a direct child page, listed below its parent body. Legacy ICNS artwork uses a transparent canvas margin: the opaque icon face occupies approximately 80.3% width, matched against the native Notes icon on the target Mac (80.5%).
